# レンズ厚みくらべ

メガネのレンズを「どのお店の、どの屈折率のレンズにすると、縁がどれくらい厚くなるか」を見比べるためのウェブアプリです。フレームの寸法と度数から縁の厚みを計算し、2つのレンズを3Dと断面図で並べて表示します。

## このアプリがしないこと

- 入力した度数、PD、フレームの情報を保存しません。ページを閉じると消えます
- 入力した情報をどこにも送信しません。計算はすべてお使いのブラウザの中で行います。外部と通信できないよう、CSP（ブラウザに守らせる約束ごと）でも止めています。HTMLファイルの中に書いたスクリプト以外は動かず、どこへも接続できない設定です
- AIを内蔵していません。フレームやレンズの情報は、利用者が自分のAI（ChatGPT、Claude、Geminiなど）に調べてもらい、その答えを貼り付ける方式です。アプリが渡すのは調べてもらうための文章（プロンプト）だけで、そこに度数やPDは含まれません
- 外部のサーバーから部品を読み込みません。3D表示の部品（three.js）もHTMLファイルの中に含めています

このリポジトリは、上の約束が守られていることを誰でも確かめられるように公開しています。

## ご注意

- 表示される厚みは計算による推定値です。実際の仕上がりは、お店の加工方法、中心の厚みの設定、フレームの形によって変わります
- 医療上の助言ではありません。度数やレンズ選びについては眼科医や眼鏡店にご相談ください
- フレームの形は、いくつかの基本形（ウェリントン、ボストン、ラウンドなど）で近似しています。キャットアイや六角形のような形は再現しきれないため、画面にその旨を表示します
- 度数が強い場合（球面と乱視を合わせて -6.00 より強い場合）は、較正した範囲の外になるため注意を表示します。-8.00 より強い場合は「どちらが薄いか」の判定を表示しません

## 公開中のファイルとこのソースが同じか確かめる

`node build.js` は、同じソースから毎回まったく同じファイルを作ります。作ったファイルの SHA-256（ファイルの指紋のような値）が、公開中のファイルの値と一致すれば、中身は同じです。

現在のソースから作られるファイルの値は次のとおりです（`dist/SHA256SUMS.txt` と同じ）。

```
39cbe88f31c6401dc62ab2d3cfc81854080e322f0db459274ec9543abfb95c69  index.html
16d95aa0ed03f2d811fb84c6f829ad31cfb84da16e28a1c548a25de1db694faf  demo.html
```

Windows の PowerShell では、次のコマンドで公開中のファイルをそのまま取り込み、値を確かめられます。ブラウザの「名前を付けて保存」はファイルの中身を書き換えることがあるため、照合には使わないでください。PowerShell は値を大文字で表示しますが、大文字と小文字の違いは無視して比べてください。

```powershell
curl.exe -sS -o index.html https://（公開先のURL）/index.html
Get-FileHash .\index.html -Algorithm SHA256
```

改行コードが変わると値も変わります。このリポジトリでは `.gitattributes` で改行コードを変えない設定にしているため、Windows で取得しても同じ値になります。

## 作り方とテスト

Node.js（18以上）があれば、追加のインストールなしで作れます。

```powershell
node build.js            # dist\index.html と dist\demo.html を作る
node tests\run-tests.js  # 計算と入力チェックのテスト（21件）
```

画面の動作確認（`tests/smoke.js`）だけは Playwright を使います。

```powershell
npm install playwright
npx playwright install chromium
node tests\smoke.js
```

## フォルダの中身

| 場所 | 内容 |
|---|---|
| `src/lens-engine.js` | 厚みの計算。画面にもネットワークにも触れない計算だけの部分 |
| `src/json-check.js` | AIの答え（JSON）を読み取り、足りない値や食い違いを見つける |
| `src/prompt-builder.js` | AIに渡す文章を作る |
| `src/app-*.js`、`src/index.tpl.html`、`src/style.css` | 画面 |
| `vendor/three/` | three.js r128（3D表示の部品） |
| `samples/` | 動作確認用の架空のデータ |
| `tests/` | 自動テスト |
| `docs/DECISIONS.md` | 設計で決めたことの記録 |
| `server/.htaccess` | 公開サーバーの設定（Apache と、Apache 互換の LiteSpeed 向け）。サーバー側からも CSP をかける |
| `dist/` | できあがったHTMLファイルと、サーバーに置く `.htaccess` |

## 計算のしくみ

- レンズの前面と後面のカーブから、縁の各点の厚みを求めています。前面のカーブは度数から一般的な選び方で決めています
- 屈折率ごと（1.60、1.67、1.74、1.76）に、ネットで公開されている厚みの表に合うよう係数を調整しています（較正）。使った表は次の2つです
  - 1.60、1.67、1.74 は、眼鏡店アイベリーのページに載っている「レンズ厚み比較表」の非球面の行から、屈折率ごとに9点（度数 -4.00、-5.00、-6.00 で、中心から 25、30、35mm の位置）を使って合わせました。ずれは最大で 1.60 が 0.10mm、1.67 が 0.06mm、1.74 が 0.04mm です。中心の厚みも同じ表の値を使っています（[アイベリー, "レンズ厚み比較表," 楽天市場, accessed October 27, 2026](https://www.rakuten.ne.jp/gold/eye-berry/image/info/info_2.html)）。表を作ったメーカー名はページに書かれていません
  - 1.76 は、れんず屋のページに載っている東海光学 ZX-AS 1.76 のフチ厚3点（度数 -2.00、-4.00、-6.00、直径 75mm）に合わせました。ずれは最大 0.02mm です（[れんず屋, "東海光学 ZX-AS 1.76非球面設計," accessed October 27, 2026](https://www.lensya.com/single/maker/tokai/zx-as/index.html)）。1.76 は3点だけで合わせていることと、中心の厚みが公表されておらず 1.74 と同じ 1.0mm と仮定していることから、ほかの屈折率より確かさは低めです
- 両面非球面の効果（片面非球面より縁がどれだけ薄くなるか）は、比べられる厚みの表が見つからなかったため、控えめに見積もった推定値です
- レンズのカーブから厚みを出す計算の土台は、Chadwick Optical の厚み計算機（[Chadwick Optical, "Lens Thickness," accessed October 27, 2026](https://chadwickoptical.com/resources/optical-calculators/lens-thickness/)）と、両面が球面のレンズ8ケースで照合しました。差は最大 0.001mm でした。この照合は自動テストに含めています（テストでは 0.01mm 未満を合格としています）。較正や形の近似が正しいかどうかは、この照合では確かめていません
- 左右それぞれのPDと、瞳の高さを計算に使います
- 前傾角やそり角（フレームの傾き）は計算に含めていません
